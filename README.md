# 佳宜幼小衔接（Joye Preschool）

面向 5-6 岁儿童的幼小衔接综合启蒙应用：**数学乐园**（10/20 以内加减、拆数、比大小、应用题）、**拼音天地**（声韵母、整体认读、拼读动画、四声）、**英语启蒙**（200+ 单词闪卡、句型），带闯关模式、错题本和学习记录。

**在线使用**：https://fatcat10-cmd.github.io/joye-preschool/

整个应用是单个 HTML 文件，打开即用，支持手机 / 平板 / 电脑浏览器。
